고양이방울방울 **1.0.11 (Version Code 17)**이 **2026년 11월 11일 오전 10시 44분(KST)** Google Play 프로덕션에 공개됐습니다. 출시율은 **100%**이며 **178개 국가·지역**에서 제공됩니다. 11월 12일 Play Console에서 해당 버전의 ‘Google Play에 제공됨’ 상태와 출시 범위를 직접 확인했습니다.

## 이번 업데이트

- 앱 시작과 백그라운드 복귀 시 최소 지원 버전을 확인하고, 업데이트가 필요하면 Google Play로 안내합니다.
- 업데이트 정책 조회에 시간·응답 크기 제한을 두고 마지막 유효 정책을 기기에 저장합니다. 처음 실행할 때 네트워크가 없어도 게임을 시작할 수 있습니다.
- Android용 앱과 게임 오버 배너·전면 광고의 연결 설정을 수정했습니다. 전면 광고는 게임 오버 2회마다 준비됐을 때 표시하며, 준비되지 않으면 건너뜁니다.
- 기존 최고 점수와 컬렉션 기록은 유지합니다.

한국어·영어 스토어 문구와 출시 노트를 확인했으며, 개인정보처리방침에는 원격 업데이트 정책 조회·외부 호스팅의 접속 정보 처리·로컬 정책 캐시 설명을 보완했습니다. 최소 지원 versionCode 정책은 이번 출시 확인 작업에서 변경하지 않았습니다.

## 확인한 내용

출시 전 정적 분석, 업데이트·위젯 테스트 15개, AAB 서명과 패키지·버전·광고 설정 검증을 통과했습니다. 11월 12일 운영 광고 노출은 사용자가 직접 확인했습니다. 자동 테스트나 AdMob 보고서의 노출 집계를 실기기 검증으로 대신 기록하지 않았습니다.
