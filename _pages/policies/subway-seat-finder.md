지하철 빈자리 찾기는 사용자의 개인정보를 중요하게 생각하며, 앱 서비스 제공에 필요한 최소한의 정보만 처리합니다.

## 1. 수집 및 이용하는 정보

앱은 다음 정보를 처리할 수 있습니다.

### 로그인 정보

Google 로그인을 사용할 경우 Firebase Authentication을 통해 로그인합니다.

- Firebase 사용자 식별자
- Google 계정 표시 이름
- Google 계정 이메일 주소
- 로그인 제공자 정보

Firebase Authentication은 Google 로그인을 처리합니다. Cloudflare D1에는 Firebase 사용자 식별자, 표시 이름, 이메일 주소, 로그인 제공자, 서비스 이용 통계와 최근 접속시간을 저장합니다. 서비스 운영과 이용 현황 확인을 위해 권한을 부여받은 관리자만 오늘 접속한 회원의 표시 이름, 이메일 주소와 최근 접속시간을 열람할 수 있습니다. 별도의 전체 접속 이력은 저장하지 않습니다.

앱 서버는 Google 계정 비밀번호를 수집하거나 저장하지 않습니다.

### 위치 정보

앱은 가까운 지하철역을 찾기 위해 기기의 위치 권한을 요청할 수 있습니다.

- 위치 정보는 가까운 역 계산에 사용됩니다.
- 정확한 위도/경도는 앱 서버에 저장하지 않습니다.
- 사용자가 위치 권한을 허용하지 않아도 앱의 일부 기능은 사용할 수 있습니다.

### 좌석 공유 정보

사용자가 좌석 정보를 공유할 때 다음 정보가 저장될 수 있습니다.

- 노선, 열차, 호차, 좌석 위치
- 내릴 역
- 공유 시각 및 만료 시각
- 도움 됐어요 수, 확인 요청 수
- 신고 사유
- 공유·좋아요·신고 시각과 처리 상태

이 정보는 다른 이용자에게 빈자리 정보를 보여주기 위해 사용됩니다.

## 2. 정보 이용 목적

수집한 정보는 다음 목적에만 사용됩니다.

- 사용자 로그인 확인
- 가까운 지하철역 찾기
- 실시간 지하철 도착 정보 조회
- 사용자가 공유한 좌석 정보 표시
- 부정확한 정보 신고 및 품질 관리
- 권한 있는 관리자의 서비스 이용 현황 확인
- 서비스 안정성 유지 및 과도한 반복 요청 방지
- 광고 제공과 성과 측정

## 3. 제3자 제공 및 외부 서비스

앱은 서비스 제공을 위해 다음 외부 서비스를 사용합니다.

- Firebase Authentication: Google 로그인
- Cloudflare Workers 및 D1: 좌석 공유 API 및 데이터 저장
- 서울 열린데이터광장 API: 지하철 실시간 도착 및 열차 위치 정보 조회
- Google AdMob: 배너 광고 제공, 성과 측정 및 부정 사용 방지

Google AdMob은 광고 제공 과정에서 광고 ID, 기기·앱 정보, 광고 상호작용 정보 및 진단 정보를 처리할 수 있습니다. 해당 정보의 처리는 Google의 개인정보처리방침과 광고 정책을 따릅니다.

- Google 개인정보처리방침: <https://policies.google.com/privacy>
- Google AdMob: <https://admob.google.com/>

앱은 사용자의 개인정보를 판매하지 않습니다.

## 4. 보관 및 삭제

좌석 공유 정보는 만료 후 활성 좌석 조회에서 제외됩니다. 전체 이용자에게 보여주는 공개 목록에는 현재 운행일의 기록만 표시합니다. 좌석·좋아요·신고 상세 기록은 좌석의 만료 시각부터 30일 동안 보관한 뒤 매일 순차적으로 삭제합니다. 정리 작업의 처리량 제한이나 일시적인 장애로 실제 삭제가 지연될 수 있습니다. 회원별 누적 공유 수, 받은 좋아요 수와 신고 수는 상세 기록 삭제 후에도 계정의 서비스 이용 통계로 유지됩니다.

사용자는 앱의 내 정보 화면에서 로그아웃하거나 회원탈퇴를 요청할 수 있습니다.

회원탈퇴 시 Firebase Authentication 계정 삭제와 함께 서버에 저장된 사용자 식별 정보는 삭제 또는 익명화됩니다.
현재 공유 중인 좌석 정보는 삭제 상태로 변경됩니다. 회원 정보에 저장된 이메일 주소와 최근 접속시간은 회원탈퇴 시 삭제됩니다.
과거 공유·좋아요·신고 기록에 연결된 사용자 식별자는 개인을 직접 식별하지 않는 익명 식별자로 변경될 수 있습니다.

로그인 관련 정보 또는 서버에 저장된 사용자 정보 삭제와 관련해 추가 문의가 필요한 경우 아래 이메일로 요청할 수 있습니다.

## 5. 보안

앱은 개인정보와 민감한 정보를 안전하게 처리하기 위해 HTTPS 등 보안 통신을 사용합니다.

API 키와 서버 비밀키는 앱에 직접 포함하지 않고 서버 환경에서 관리합니다.
