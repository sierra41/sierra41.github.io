지하철 빈자리 찾기는 지하철 이용자가 곧 비워질 좌석 정보를 쉽게 공유하고 확인할 수 있는 앱입니다.

가까운 역의 실시간 지하철 도착 정보를 확인하고, 내가 탄 열차와 호차, 좌석 위치, 내릴 역을 그림 방식으로 선택할 수 있습니다.

다른 이용자는 같은 열차의 좌석 정보를 보고 곧 비워질 자리를 더 쉽게 찾을 수 있습니다.

[Google Play에서 설치하기](https://play.google.com/store/apps/details?id=com.sicorp.subwayseatfinder){: .btn .btn--primary}

![지하철 빈자리 찾기 스토어 홍보 이미지]({{ '/assets/images/apps/subway-seat-finder/feature-graphic.png' | relative_url }})

## 주요 기능

- 가까운 지하철역 기준 열차 선택
- 실시간 지하철 도착 정보 확인
- 열차, 호차, 좌석 위치를 그림으로 선택
- 내릴 역 선택
- 곧 비워질 좌석 정보 공유
- 부정확한 정보 확인 요청
- 오늘의 빈자리 목록과 좌석 위치 확인, 좋아요
- 내 공유 기록 확인과 계정 삭제

좌석 정보는 이용자 공유를 바탕으로 하므로 실제 상황과 다를 수 있습니다. 현재는 서울 지하철 중심으로 제공하며, 이동할 때에는 주변 승객과 안전을 먼저 살펴 주세요.

Google 로그인으로 이용하며 Google Play 인앱 업데이트를 제공합니다.

## 데이터 안내

지하철 빈자리 찾기는 가까운 지하철역을 찾기 위해 기기의 위치 권한을 요청할 수 있습니다.

위치 정보는 가까운 역 계산에 사용되며, 정확한 위도/경도는 앱 서버에 저장하지 않습니다.

본 앱은 서울특별시 공공데이터를 활용합니다.

## 프로그램 구조

```text
Flutter Android 앱
  → Firebase Auth: Google 로그인과 ID 토큰
  → Cloudflare Worker: 인증 검증, 좌석 API, 요청 제한, 짧은 캐시
    → Cloudflare D1: 사용자·좌석·좋아요·신고와 누적 집계
    → 서울 공공데이터: 실시간 열차 정보
```

Firebase는 인증에 사용하며 좌석 데이터는 D1에서 관리합니다. 앱이 외부 지하철 API를 직접 호출하지 않고 Worker가 중계합니다. 위치 정보는 가까운 역 계산에 사용하며 정확한 위도·경도를 앱 서버에 저장하지 않습니다.

| 영역 | 역할 |
| --- | --- |
| `lib/src/auth/` | Firebase Google 로그인 |
| `lib/src/data/` | API 저장소와 공통 요청 관리자, 로컬 샘플 저장소 |
| `lib/src/models/` | 열차·좌석 모델 |
| `lib/src/ui/` | 열차·호차·좌석 탐색, 공개 기록, 내 정보 |
| `server-worker/` | 인증·좌석·관리자 API, D1 마이그레이션, 정리 작업 |
| `store-assets/play-console/` | 스토어 제출용 에셋 작업본 |
